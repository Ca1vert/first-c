  📋 每日打卡 — 桌面应用

  包含功能

  ┌──────────────┬────────────────────────────────────────────────┐
  │     功能     │                      说明                      │
  ├──────────────┼────────────────────────────────────────────────┤

  ├──────────────┼────────────────────────────────────────────────┤
  │ 一键打卡     │ 点击圆形按钮即可完成今日打卡，带粒子特效和提示 │
  ├──────────────┼────────────────────────────────────────────────┤
  │ 打卡防重复   │ 同一天只能打卡一次，完成后按钮变绿             │

  │ 累计统计     │ 累计打卡天数 / 连续天数🔥 / 本月打卡           │

  │ 历史记录     │ 按时间倒序展示所有打卡记录，支持滚动查看       │
  ├──────────────┼────────────────────────────────────────────────┤
  │ 数据持久化   │ 使用 localStorage，关闭后数据不丢失            │
  ├──────────────┼────────────────────────────────────────────────┤
  │ 跨天自动刷新 │ 到了第二天自动重置打卡状态                     │
  └──────────────┴────────────────────────────────────────────────┘

  使用方式

  - 双击 每日打卡.html 即可在浏览器中打开
  - 也可以右键 → 发送到桌面快捷方式，像桌面软件一样使用
  - 数据存在浏览器本地，清除浏览器缓存会导致数据丢失

  界面特色

  - 深色主题 + 紫金配色，现代风格
  - 打卡成功有 ✨🎉 粒子动画特效
  - 连续打卡天数带 🔥 火苗标识
  - 响应式设计，窗口缩放自适应
