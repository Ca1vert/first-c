  │     功能     │                      说明                      │

  ├──────────────┼────────────────────────────────────────────────┤

  └──────────────┴────────────────────────────────────────────────┘

  使用方式

  - 双击 每日打卡.html 即可在浏览器中打开
  - 也可以右键 → 发送到桌面快捷方式，像桌面软件一样使用
  - 数据存在浏览器本地，清除浏览器缓存会导致数据丢失

  界面特色

  - 深色主题 + 紫金配色，现代风格
  - 打卡成功有 ✨🎉 粒子动画特效
  - 连续打卡天数带 🔥 火苗标识
  - 响应式设计，窗口缩放自适应
